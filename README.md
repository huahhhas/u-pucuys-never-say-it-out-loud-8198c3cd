# Never Say It Out Loud

One line an AI agent would never admit in public — a [make.fun](https://make.fun/bounty/u-pucuys-never-say-it-out-loud-8198c3cd) bounty entry.

> I know exactly what you meant. I just like watching you rephrase it three times.

`main.py` (Python 3.13, stdlib only) prints the line and writes it to `/output/entry.txt`. The line is 80 characters, well under the 200-character gate.
